# Shubhranil Layek — developer profile website

Static personal profile site for [Shubhranil Layek](https://github.com/shubhranillayek), served at https://shubhranillayek.github.io/ after GitHub Pages deployment.

## Content

- A plain-HTML developer profile, original projects, demo links and practical questions.
- ProfilePage, Person and SoftwareSourceCode JSON-LD matching the visible content.
- Canonical and social metadata, robots.txt and a three-URL sitemap.

## Deployment

GitHub Pages: deploy from the repository's default branch at the root. `.nojekyll` keeps this a plain static site. Confirm that the actual default branch is `main` before configuring the source.

## Local preview

```bash
python3 -m http.server 8000
```

Open http://localhost:8000. The page does not need JavaScript or a build system to show its main content.

## Search and answer-engine visibility

The site improves public content clarity and crawlability. Structured data is not a guarantee of rich results, indexing, rankings or AI citations. Search Console ownership verification and sitemap submission require a separately authorized setup; neither is included in this publication package. No analytics or tracking scripts are included.
